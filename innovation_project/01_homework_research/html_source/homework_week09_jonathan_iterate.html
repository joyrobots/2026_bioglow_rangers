Part 1 — Practice My Part

Iterate

(Show the video.) I ride my bike at Bruce's Mill Conservation Area. An ash tree there was infested with EAB and had to be cut down.

Our first version was a flat vibration sensor that sat on the bark. One problem we found is that it might not detect the larvae, because they are too small and the bark might be too thick. If it misses them, the ash tree might already be dead before we detect any sound. So for our second version, we added a needle to go deeper into the tree's bark, and we upgraded the sensor's sensitivity. We also searched for the hertz of the EAB larvae, so we can set the sensor to that exact hertz. For our next iteration, we plan to put a waterproof cover on the sensor.

Next, Jasper will talk about how we connected with experts.
