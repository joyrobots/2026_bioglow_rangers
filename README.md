## 🧭 Repository Structure & Engineering Single Source of Truth (SSOT)

This repository serves as the transparent digital engineering record for **JoyRobots Rangers (77358)**, documenting our entire Engineering Design Process (EDP) across the 2026–2027 season.

* **`commit_test/`**: Training ground for junior engineers to master Git check-in protocols.
* **`robot_game/`**: SPIKE Prime (`.llsp3`) codebase managed across 3 strict engineering phases:
  * `phase1_single_mission/`: Isolated, atomic mission runs.
  * `phase2_multi_mission/`: Multi-mission launch sequences and attachment combos.
  * `phase3_competition_ready/`: Match-locked, 150-second freeze builds.
* **`robot_design/`**: Scanned audit sheets, navigation pseudocode, chassis center-of-gravity logs, and attachment CAD drawings.
* **`innovation_project/`**: Project **Tree Stethoscope** — an Edge-AI acoustic bio-sentinel detecting Emerald Ash Borer (EAB) larvae beneath tree bark using M5Stack and contact piezo sensors before visible canopy collapse.
* **`portfolio_assets/`**: Field trip photos (Meander Park Tree Tour), failure analysis museum, and 5-minute competition pitch scripts.
